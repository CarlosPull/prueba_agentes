# Memoria del Agente Frontend (`dev-front`)

## Aprendizajes del Proyecto Vue

- **Framework**: Vue 3 + TypeScript + Vite.
- **Rutas**: Configuradas en `src/router.ts`.
- **Servicios**: Consumo de APIs en `src/services/authApi.ts`.
- **Pruebas**: Vitest ejecutable con `./node_modules/.bin/vitest run`.
